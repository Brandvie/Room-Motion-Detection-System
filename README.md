# Room-Motion-Detection-System

Overview

An IoT project using a Raspberry Pi and a PIR motion sensor to detect movement in a room. When movement is detected, the system can send alerts to an IoT dashboard over Wi-Fi.

Technologies

Raspberry Pi

PIR Motion Sensor 

Python

Wi-Fi / IoT Dashboard

Features

Detects movement in a room

Displays motion detection status

Records motion events

Sends alerts through an IoT dashboard

How It Works

The PIR sensor detects movement and sends a signal to the Raspberry Pi. Python processes the signal and can send the event to a dashboard over Wi-Fi.

Project Goal

To develop a simple IoT security system that monitors movement in a room.
